# Conteudo Para LinkedIn

Este documento contem textos prontos para divulgar o projeto BankGuard no LinkedIn.

## Versao Curta

```text
Conclui o BankGuard, um projeto de portfolio em Engenharia de Dados.

O objetivo foi simular uma plataforma de monitoramento e analise de transacoes bancarias, conectando:

- Python
- PostgreSQL
- ETL
- Modelagem relacional
- Modelagem dimensional
- FastAPI
- Swagger
- Docker
- Testes automatizados
- GitHub Actions

O projeto recebe dados em CSV, valida qualidade, carrega um banco PostgreSQL, monta um Data Warehouse e expoe informacoes por uma API REST.

Repositorio:
https://github.com/danielgermano-data/bankguard
```

## Versao Completa

```text
Estou construindo minha transicao para Engenharia de Dados com projetos praticos e hoje finalizei uma etapa importante: o BankGuard.

O BankGuard e uma plataforma simulada de monitoramento e analise de transacoes bancarias.

A ideia foi criar um projeto de ponta a ponta, passando por etapas que aparecem em ambientes reais de dados:

- Ingestao de dados em CSV
- Validacao de qualidade dos dados
- Pipeline ETL em Python
- Banco PostgreSQL com modelo relacional
- Data Warehouse com fato e dimensoes
- Consultas SQL analiticas
- API REST com FastAPI
- Documentacao automatica via Swagger
- Docker Compose para ambiente local
- Testes com Pytest
- Lint com Ruff
- CI com GitHub Actions

Alguns endpoints implementados:

- GET /clientes
- GET /transacoes
- GET /estatisticas
- GET /fraudes

No endpoint de estatisticas, o projeto calcula total de transacoes, valor total movimentado, ticket medio e quantidade de transacoes suspeitas.

Esse projeto me ajudou a praticar conceitos importantes de Engenharia de Dados, como modelagem relacional, modelagem dimensional, qualidade de dados, ETL, SQL e exposicao de dados por API.

Repositorio:
https://github.com/danielgermano-data/bankguard

Seguirei evoluindo o projeto com autenticacao, dashboard analitico, mais testes e orquestracao de pipelines.
```

## Versao Com Tom de Aprendizado

```text
Depois de alguns dias estudando e implementando, publiquei meu projeto BankGuard no GitHub.

Como estou em transicao para Engenharia de Dados, quis criar algo que fosse alem de um notebook ou script isolado.

O BankGuard simula um ambiente bancario e trabalha com dados de clientes, contas, agencias, produtos e transacoes.

O fluxo principal ficou assim:

CSV -> ETL em Python -> PostgreSQL -> Data Warehouse -> FastAPI -> Swagger -> JSON

Tecnologias usadas:

- Python
- SQL
- PostgreSQL
- FastAPI
- Docker
- Pandas
- Pytest
- Ruff
- GitHub Actions

Tambem documentei a arquitetura, a modelagem relacional, a modelagem dimensional e preparei respostas para entrevistas tecnicas sobre o projeto.

Repositorio:
https://github.com/danielgermano-data/bankguard

Esse projeto representa um passo importante na minha jornada para atuar com Engenharia de Dados.
```
